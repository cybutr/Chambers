--- Execute: #region river sources ---

Collect all valid source candidates into a List<(int x, int y)>:
- Iterate all tiles with nested for(x) for(y)
- A tile is a valid source if ALL of:
  - ctx.elevation[x, y] >= 0.50 && ctx.elevation[x, y] <= 0.72
  - ctx.mapData[x, y] is not Ocean, Mountain, MountainDeep, Snow, Border

Determine source count:
  int sourceCount = Math.Max(3, ctx.width * ctx.height / 800);

If candidates.Count == 0, return early.

Shuffle candidates using Fisher-Yates with ctx.rng:
  for (int i = candidates.Count - 1; i > 0; i--)
  {
      int j = ctx.rng.Next(i + 1);
      (candidates[i], candidates[j]) = (candidates[j], candidates[i]);
  }

Take the first Math.Min(sourceCount, candidates.Count) candidates as sources.

--- Execute: #region river tracing ---

For each selected source (sx, sy):
  TraceRiver(ctx, sx, sy);

After all rivers are traced, mark shallow edges:
  MarkShallowEdges(ctx, TileId.River, TileId.RiverShallow);
  MarkShallowEdges(ctx, TileId.Lake, TileId.LakeShallow);

--- Private: TraceRiver(GenerationContext ctx, int sx, int sy) ---

- int w = ctx.width, h = ctx.height;
- Use a HashSet<(int, int)> visited to prevent loops (add each step before moving)
- Start at (sx, sy), set ctx.mapData[sx, sy] = TileId.River
- Loop (max iterations = w + h to prevent infinite loops):
  - If current tile is Ocean or Border: stop
  - Add current (cx, cy) to visited
  - Find the lowest-elevation 4-cardinal neighbor (N/S/E/W only — dx or dy, not both):
    - int[] ddx = { 0, 0, 1, -1 };
    - int[] ddy = { 1, -1, 0, 0 };
    - For each of the 4 directions: compute nx = cx + ddx[i], ny = cy + ddy[i]
    - Bounds check: if (nx < 0 || nx >= w || ny < 0 || ny >= h) skip
    - Skip if (nx, ny) is in visited
    - Track the neighbor with the lowest ctx.elevation[nx, ny]
  - If no valid lower neighbor found (lowestElev >= ctx.elevation[cx, cy] OR no neighbor found):
    - FormLake(ctx, cx, cy); return;
  - Move to (bestNx, bestNy):
    - If ctx.mapData[bestNx, bestNy] != TileId.Ocean && ctx.mapData[bestNx, bestNy] != TileId.Border:
      - ctx.mapData[bestNx, bestNy] = TileId.River;
    - cx = bestNx; cy = bestNy;

--- Private: FormLake(GenerationContext ctx, int x, int y) ---

Flood-fill a lake basin centered on the termination point up to radius 5.

- int w = ctx.width, h = ctx.height;
- const int lakeRadius = 5; // max radius from termination point
- Use a Queue<(int, int)> for BFS; HashSet<(int, int)> lakeVisited
- Enqueue starting point (x, y); add to lakeVisited
- BFS expansion:
  - Dequeue (cx, cy)
  - Mark ctx.mapData[cx, cy] = TileId.Lake (if not Ocean or Border)
  - For each 4-cardinal neighbor (nx, ny):
    - Bounds check: if (nx < 0 || nx >= w || ny < 0 || ny >= h) continue;
    - Skip if in lakeVisited
    - Skip if ctx.mapData[nx, ny] == TileId.Ocean || ctx.mapData[nx, ny] == TileId.Border
    - Only expand if GetDistance(x, y, nx, ny) <= lakeRadius
      (GetDistance not available — use: Math.Sqrt((nx-x)*(nx-x) + (ny-y)*(ny-y)) <= lakeRadius)
    - Enqueue and add to lakeVisited

--- Private: MarkShallowEdges(GenerationContext ctx, TileId waterTile, TileId shallowTile) ---

- int w = ctx.width, h = ctx.height;
- Nested for(x) for(y) over all tiles
- If ctx.mapData[x, y] != waterTile: continue
- Check all 4 cardinal neighbors:
  - int[] ddx = { 0, 0, 1, -1 };
  - int[] ddy = { 1, -1, 0, 0 };
  - For each direction: compute nx, ny; bounds check; if ctx.mapData[nx, ny] is not waterTile and not shallowTile and not Ocean and not Border:
    - ctx.mapData[x, y] = shallowTile; break;
