RestoreSnow:
- const double snowThreshold = 0.78; // elevation above which mountain peaks get snow
- Nested for(x) for(y) over width/height
- If mapData[x,y] != TileId.Mountain AND mapData[x,y] != TileId.MountainDeep: continue
- If elevation[x,y] <= snowThreshold: continue
- mapData[x,y] = TileId.Snow

MarkOceanShallow:
- int[] ddx = { 0, 0, 1, -1 }; int[] ddy = { 1, -1, 0, 0 };
- Local int w = ctx.width, h = ctx.height
- Nested for(x) for(y)
- If mapData[x,y] != TileId.Ocean: continue
- Use a local bool flag to check cardinal neighbors:
  bool nearLand = false;
  for (int d = 0; d < 4; d++)
  {
      int nx = x + ddx[d], ny = y + ddy[d];
      if (nx < 0 || nx >= w || ny < 0 || ny >= h) continue;
      if (ctx.mapData[nx, ny] != TileId.Ocean && ctx.mapData[nx, ny] != TileId.Border)
      {
          nearLand = true;
          break;
      }
  }
  if (nearLand) ctx.mapData[x, y] = TileId.OceanShallow;

MarkBeaches:
- Same cardinal neighbor pattern
- If mapData[x,y] != TileId.Plains AND mapData[x,y] != TileId.Forest: continue
- If any cardinal neighbor is Ocean, OceanShallow, River, Lake, or LakeShallow: set mapData[x,y] = TileId.Beach; break

MarkBeachDark:
- If mapData[x,y] != TileId.Beach: continue
- Count cardinal neighbors where neighbor is Beach or OceanShallow
- If count >= 3: mapData[x,y] = TileId.BeachDark

Conventions (mandatory):
- No XML doc comments, no inline // comments except the one on snowThreshold constant

- Brace-free single-line guard: if (condition) continue;
- No LINQ anywhere
- No Map class reference anywhere in the file
- Expression-bodied Name property: public string Name => "FeaturePass";
