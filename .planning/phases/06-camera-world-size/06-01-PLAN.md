CRITICAL — keybind registry is NOT additive:
`Keybinds.Bind` is `Binds[context][(key, mods)] = commandId` — a dictionary assignment. One key maps to exactly one command. Binding UpArrow to "PanUp" after binding it to "ChamberLast" silently overwrites the chamber-switch. To give arrow keys dual behaviour, the COMMAND LAMBDA must do both things. Do not call `keybinds.Bind` twice for the same key.

Multi-key bind pattern (line 376) — keys can bind to a single command, not multiple commands to one key:
```csharp
keybinds.Bind(InputContext.World, [ConsoleKey.P, ConsoleKey.Spacebar], "ToggleUpdate");
```

IMPORTANT — keybind architecture constraint: `keybinds.Bind` writes `Binds[context][(key, mods)] = commandId`. It is a dictionary assignment, NOT an append. Binding the same key twice leaves only the last binding. Do NOT add a second `keybinds.Bind` call for arrow keys — the second call would erase the first. This is confirmed by `Core/Keybinds.cs` line 37: `Binds[context][(key, ConsoleModifiers.None)] = commandId` — last-write wins, so compound lambdas are the only way to attach both pan and chamber-switch to a single key.

The correct approach: replace the four `RegisterCommand` lambdas for `ChamberPrev`, `ChamberNext`, `ChamberFirst`, and `ChamberLast` so each lambda does BOTH the chamber-switch AND the pan. The `keybinds.Bind` calls stay unchanged (one Bind per arrow key).

Replace lines 411–418 (the four RegisterCommand+Bind pairs for arrow keys) with:

```csharp
keybinds.RegisterCommand("ChamberPrev", () =>
{
    if (!isCommandInputMode && (!IsTemperatureRendering || !IsHumidityRendering)) PanCamera(-5, 0);
    if (chambers.Count > 1 && currentChamberIndex > 0) chamberSwitch(currentChamberIndex - 1);
});
keybinds.Bind(InputContext.World, ConsoleKey.LeftArrow, "ChamberPrev");
keybinds.RegisterCommand("ChamberNext", () =>
{
    if (!isCommandInputMode && (!IsTemperatureRendering || !IsHumidityRendering)) PanCamera(5, 0);
    if (chambers.Count > 1 && currentChamberIndex < chambers.Count - 1) chamberSwitch(currentChamberIndex + 1);
});
keybinds.Bind(InputContext.World, ConsoleKey.RightArrow, "ChamberNext");
keybinds.RegisterCommand("ChamberFirst", () =>
{
    if (!isCommandInputMode && (!IsTemperatureRendering || !IsHumidityRendering)) PanCamera(0, 3);
    if (chambers.Count > 1 && currentChamberIndex != 0) chamberSwitch(0);
});
keybinds.Bind(InputContext.World, ConsoleKey.DownArrow, "ChamberFirst");
keybinds.RegisterCommand("ChamberLast", () =>
```
